02 Roles & Authority Matrix

Tier Role Scope of Authority Primary Capabilities
Tier 1 Platform Super Admin (Us) Global SaaS Platform Manage tenant organizations, global subscriptions, platform billing, global DLP presets. (Zero raw customer data visibility).
Tier 2 Organization Admin Entire Customer Org DNS domain verification, create/manage departments, set Org-wide global DLP policies, invite employees, full incident stream & SIEM export.
Tier 2 Org Auditor Entire Customer Org Read-only compliance views, audit log exports, violation incident reviews.
Tier 3 Department Admin (Team Lead) Assigned Category Only (e.g. Engineering) Create department-specific DLP rules (e.g. AWS key blocking), assign department members, view department-level violation incidents only.
Tier 4 Employee Personal Browser Extension Real-time DLP enforcement against ChatGPT, Claude, etc. Undergoes both Org-wide + Department rules.

03 Hierarchical Policy Inheritance ("Strictest Wins")

Employees inherit two layers of DLP policies. If a prompt triggers multiple policies, the most protective action is enforced automatically:

Layer 1: Org-Wide Global Policies

  • Applies to every single employee in the company.
  • Examples: Block Credit Cards, Block SSN, Mask Customer Passwords.

Layer 2: Department-Specific Policies

  • Applies only to members of that specific category.
  • Engineering: Block AWS keys, GitHub tokens, Database connection strings.
  • Finance: Block customer IBANs, tax files, payroll sheets.
  • HR / Legal: Block internal offer letters, employee performance reviews.

Conflict Resolution Hierarchy

BLOCK > MASK / REDACT > WARN > LOG_ONLY
