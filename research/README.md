# SecureGPT Research & Experimentation Engine

This directory tracks research investigations, quantitative experiments, benchmark definitions, and formal engineering findings.

## 📁 Directory Structure

```
research/
├── literature/        # Summaries of academic papers & external models (e.g. GLiNER, TrOCR)
├── experiments/       # Numbered, reproducible experiment runs (EXP-001, EXP-002...)
│   ├── detection/     # NER model quantization & regex classification experiments
│   └── ocr/           # Image filter tuning & OCR engine experiments
├── benchmarks/        # Reproducible benchmark protocols & ground-truth references
├── reports/           # Human-readable experimental evaluation reports
└── findings/          # Canonical long-term takeaways and architecture validations
    ├── detection.md
    └── ocr.md
```
